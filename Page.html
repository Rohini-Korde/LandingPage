Music That Understands Your Mood

MoodMelody is a mood-based music recommendation system developed using Spring Boot, JWT authentication, and intelligent recommendation logic.

Key Features

JWT Authentication

Secure login and registration system using JWT tokens and Spring Security.

Mood-Based Recommendation

Recommends songs based on the current mood of the user.

Favorites Management

Users can save and manage their favorite songs easily.

Role-Based Access

Separate access control for ADMIN and USER roles.

Docker Integration

MySQL database runs securely inside Docker containers.

REST APIs

Scalable RESTful APIs developed using Spring Boot.

How It Works

1

User Login

About MoodMelody

MoodMelody is a secure mood-based music recommendation system developed using Spring Boot and MySQL. The system recommends songs according to user emotions while maintaining secure authentication and role-based access.

The project demonstrates modern backend development concepts including JWT authentication, REST APIs, Docker integration, layered architecture, and personalized recommendation logic.
